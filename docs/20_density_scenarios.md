# 20. Сценарії з різним накладанням подій

Підготовлено дев'ять синтетичних сценаріїв Києва: три профілі розміщення по три seed (`41`, `42`, `43`). У кожному — 250 модельованих відключень, період `[2026-07-01, 2026-10-01)` UTC. Це контрольовані сценарії, а не історія фактичних знеструмлень.

- `sparse`: події розміщені у різних двогодинних інтервалах без накладань.
- `uniform`: моменти початку рівномірно розподілені у вікні з урахуванням тривалості.
- `clustered`: моменти початку згруповані у десять коротких часових кластерів.

Для кожного seed усі три профілі використовують однаковий поелементний список тривалостей від 30 хвилин до 2 годин; змінюється розташування подій. Це парний синтетичний дизайн, не незалежні вибірки між профілями. Різні seed дають окремі псевдовипадкові реалізації. Фіксований час і кількість подій допомагають досліджувати профіль накладань; разом із ним можуть змінюватись число меж, злитих станів та інші характеристики, тому не можна приписувати майбутню різницю часу одному параметру без аналізу планів.

```powershell
python -m scripts.generate_density_scenarios
python -m scripts.load_density_scenarios
python -m scripts.verify_density_scenarios
```

Генератор записує дев'ять CSV і manifest з параметрами, кількістю пар перетинних відключень, максимальною одночасністю, довжиною об'єднання та SHA-256 у `data/synthetic/density_scenarios/`, який виключено з Git. Існуючі файли не перезаписуються. Завантажувач перевіряє хеші та відтворює кожен рядок, а потім додає сценарії однією транзакцією без перезапису наявних. Метадані — у `scenario.density_manifest`; усі події позначені `synthetic`. Перевірка незалежно звіряє кожен запис та кожен стан із Python-еталоном і порівнює хеш джерела тривог із завантаженням.

У pgAdmin:

```sql
SELECT scenario_id, profile, seed, event_count, overlap_pairs,
       peak_simultaneous, union_seconds
FROM scenario.density_manifest
ORDER BY profile, seed;
```

Побудова сценаріїв і перевірка їх коректності не є вимірюванням продуктивності. Результати повторюваної серії вимірювань наведено в [документі 21](21_density_benchmark.md).
